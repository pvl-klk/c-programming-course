# Пояснения к решению

- Поля заголовка выровнены по левому краю вне зависимости от типа данных
- Пустые строки игнорируются
- Все пробельные символы с начала и конца строк обрезаются
- Поддерживаются рваный CSV (разное количество значений в строках) и пустые ячейки


# Пояснения к структуре проекта

- Программа собирается в директорию `/out`
- Тесты собираются в директорию `/tests`
- Для текстирования используютя фикстуры
